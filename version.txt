## 0.4.5
- 新增：**技能市场分成两个并列的市场**（同一套展示框架，顶部两个按钮切换）
  · **官方市场**：仍旧走 GitHub（我维护、随仓库发版）
  · **用户市场**：走官网接口（社区投稿，**只返回审核通过**的条目），卡片上标「用户投稿 · 已过审」
  · 两个市场都做了**分页**（每页 12 条 + 页码条）
  · 用户市场装进来的技能**默认是停用状态**（社区投稿、非官方出品，先看一眼正文再打开）
- 新增：**插件内投稿**（投稿只允许从扩展发起）
  · 「我的技能」每个技能上点「投稿到用户市场」→ 提交后进入待审核队列，通过才上架
  · 提交后拿到的 **editToken 直接显示在该技能的卡片上**（可复制 / 查状态 / 撤回投稿）——
    只有提交者自己看得到；技能更新、重装都不会把它弄丢
  · 官网不再收投稿（网页一关 token 就找不回来），服务端也要求"带插件标记"才收
- 修复：**提问里附带的截图不显示**
  · 根因：在"还没有工作区的页面"上贴图后发消息时，附件在读取之前就被清空了 → 图根本没进消息
  · 现在图片以 **base64 存进那条消息**并在气泡里显示**缩略图**，**点一下看大图**（Esc 或点任意处关闭），
    重开侧栏仍在，**随会话删除一起消失**（不留孤儿数据）；并加了 `unlimitedStorage` 免得撑爆配额
- 修复：**发过的内容切页又出现在输入框**（草稿）
  · 发送成功后清掉对应草稿；没有工作区的页面**按标签页各存各的**（不再互串）；
    发送失败会把文字放回输入框。没发出去的草稿仍然跟着页面保留（这是原本的好意，保留）
- 修复：**关掉临时标签页后一直报「目标标签页已经被关闭了」**
  · `closetab` 之后把目标自动换到别的活页；动作前的校验改为"重试 + 重读工作区列表"，
    真读不到但还有别的页就自己换过去继续；文案也区分"读不到（可能在跳转）"与"确实被关"
- 修复：**开了自动执行，切换标签页这类调用还是弹出"执行/取消"等你点**
  · 自动模式下卡片直接进入"执行中"，不再出现可点的执行/取消；
    并且待确认支持**跨面板实例**（在另一份侧栏里点，也能落到真正在跑的那份）
- 修复：**导入技能时元数据会跑进正文**（点开编辑框能看见 `name:` / `title:` 那几行，再保存就变成两份元数据）
  · 两个原因：① 导入时把"文件全文"当成了正文（一处变量漏改）；② 老格式只要文件开头多了 BOM 或一个空行，
    整块 frontmatter 就解析失败、被当成正文收进来
- 改进：**导出 / 复制技能改用新格式** —— 元数据放在 `<!-- qingniao-skill … -->` HTML 注释里，不再用 Markdown 的 `---`
  · 注释在任何 Markdown / HTML 渲染里**都不显示**，也不会被 Markdown 语法吃掉
    （老的 `---` 会被渲染成一条水平线，元数据那几行直接露在正文里）
  · 导入**同时兼容新格式与老格式**（技能市场里那批 `SKILL.md` 照常工作），并且容忍
    BOM、开头空行、CRLF、`...` 收尾、fence 尾随空格
  · 往编辑框里**粘贴一整份 SKILL.md 再保存**：元数据会被收进表单字段，正文只留正文（不会再叠出第二份）
- 新增：设置页「**清理元数据残留**」按钮 —— 一键把历史脏数据（正文里混进元数据块的技能）洗干净

## 0.4.4
- 新增：**自定义请求头**（给 Cloudflare AI Gateway 这类**鉴权网关**用）
  · 供应商卡片里可加任意请求头（名称 + 值），随每次模型请求一起发出去；
    Cloudflare AI Gateway 常用头 `cf-aig-authorization` 有一键添加
  · 值里可以用 **`{{key}}`** 代表当前轮询到的 API Key（例如 `Bearer {{key}}`）
  · 自定义的 `Authorization` / `x-api-key` 会**覆盖**自动鉴权头（以你的为准）；
    名字不合法的头自动跳过（否则 fetch 会直接报错）
- 新增：**接入方式二选一：OpenAI 兼容 / Anthropic 兼容**（每个供应商各自选）
  · OpenAI 兼容：`{BaseURL}/chat/completions`，`Authorization: Bearer <Key>`（默认，行为不变）
  · Anthropic 兼容：`{BaseURL}/messages`，自动带 `x-api-key` 与 `anthropic-version: 2023-06-01`
    · system 提示词自动挪到独立的 `system` 字段；相邻同角色消息自动合并（Anthropic 要求交替）；
      图片块 `image_url` 自动换成 Anthropic 的 `image` 块（data URL 走 base64，网址走 url）；
      `max_tokens` 必填会自动补上；流式事件按 Anthropic 的 `content_block_delta` 解析
    · 「深度思考」开关在这条接入上不发送（Anthropic 的 extended thinking 参数与 OpenAI 那套不通用）
- 修复：**富文本编辑器 / 复杂页面上"时好时坏"的输入与点击**（用户反馈的"有些网站试很多轮都不成、开始成功后来又迷失"）
  · **逐字输入这条路本来就是坏的**：拟人打字的等待函数在早前重构里被删掉了，`type` 动作与
    `fill human:true` 一调用就报 "autoSleep is not defined" —— 现在补回（这是"输入有问题"最实的一条）
  · **编辑器要"真点一下"才认输入**：ProseMirror / Quill / Slate / Lexical 这类靠 mousedown 建立选区，
    只 focus() 的话内容会落到它看不见的地方 → 现在 fill/type 都会先派发完整的鼠标序列（含坐标）再写
  · **编辑器每次输入会重建 DOM**：旧引用失效后继续往里敲等于对着空气打字 →
    现在逐字输入**每敲一个字符都重新定位活节点**（换节点后重建焦点/选区），
    回读也以"原节点的容器"为锚找回**同一个**编辑器（不再读到页面上别的输入框）
  · **"写对了却报失败"**：编辑器把内容渲染到子节点/容器时，严格比对会误判 → 现在再确认一次
    "期望的每一行是否真的出现了"，不再误报（误报会让 AI 反复重试、最后彻底迷失）
  · **连续失败会明确制止**：同一个输入区域连续失败 2 次以上时，结果里直接写
    "不要再对同一个编号重复 fill/type 了"并给出换手段（find/a11y/截图、先 click、改 type）
  · **内容脚本抛异常不再变成"页面未响应动作"**：现在把真实错误原文带回来（以前完全看不出原因）
- 修复：**多标签页时的三处"同步"问题**（都是"每个标签页一份侧栏文档、各自内存副本"引起的）
  · 在 A 页勾了「自动执行」，AI 在 B 页干活时照样弹确认框 → 现在设置改动会同步到每一份侧栏，
    并且"能不能自动执行"改为以设置为准（不再看那份文档里可能过时的勾选框）
  · **切到 AI 自己开的那一页时显示"新对话"** → 现在工作区列表改动会同步到每一份侧栏，
    那一页立刻显示**同一份会话**（含历史消息；AI 的新回复、你的发送与终止也都跟着同步）
  · **AI 报"找不到自己创建的标签页/已关闭"，其实它开着** → 找不到时会先重读一遍工作区列表再试，
    报错文案也分成"不在本工作区"和"确实被关了"；AI 开过的页改为**落盘记录**，换一份侧栏也认
- 修复：**确认框的「执行 / 取消」点了没反应**
  · 原因：切换标签页/同步会话时消息列表会重建，卡片是新建的、挂在旧卡片上的点击监听随之消失
  · 现在改用**事件委托**（文档级统一拦截），卡片怎么重建都点得动；点了立刻有"执行中…/已取消"反馈
  · 顺带修：横条自愈失效（任务已结束时横条不收）—— 原因是存储监听的某一分支抛异常，
    后面的同步整段跑不到
- 修复：**并入 / 移出工作区后的视图**
  · 并入：这一页立刻显示**那个工作区的会话**（同一份、含历史），不再是它自己的空对话
  · 移出：这一页换回**自己的新对话**页
- 新增：**技能导入（支持拖拽）**
  · 设置页「我的技能」里把导出的 `<id>-SKILL.md`（或任何 SKILL.md）**拖进来**即可导入；
    也支持点「导入 .md」选文件、一次拖多个、直接拖一段文本
  · 解析与导出对称：frontmatter 的 name/title/description/version/author/tags/icon + 正文完整保留；
    也兼容市场目录那样的 JSON（含 skills 数组）
  · 同名时问你一句：覆盖原技能，还是保留成新副本（自动加 -2 后缀）；坏文件只跳过并说明原因
- 新增：**多标签页协作**（AI 可以自己开一页去浏览/总结，干完再回到原来的页继续）
  · `newtab` 新开标签页：**后台静默打开**（不抢焦点、不动你正在看的页），自动并入本工作区、**共用同一份对话**
  · **每个动作可带 `tab`:id 指定"打在哪一页"** —— 无论你是否切换标签页，AI 都打在它指定的那一页上，两页绝不串
    （a11y / find / 截图 / 点击填写 / 自动化 全都支持；不写时沿用本轮"粘性"目标；写错会报错并列出可用 id）
  · 工作区标签页列表**带 id** 显示；动作结果回显「本步作用在：id=…」，你和 AI 都能核对
  · `closetab` 关闭临时页：**只能关 AI 自己开的**，绝不关你的页面（是否关闭由 AI 判断）
  · 修复：`switchtab` 的提示与实现不一致（列表给的是位置编号、实现却比真实 id）→ 现在两种都收
- 修复：**富文本多行内容被压成一行**（换行丢失）
  · 富文本改为**按行插入真正的换行**（Enter / insertParagraph，`<br>` 兜底），不再塞会被当空格渲染的 \n
  · 逐字输入遇到换行会**按 Enter**（以前等于没换行）
  · 回读校验**保留换行**并逐行比对；换行没写进去会**直接报错**（告诉你期望/实际行数），不再静默通过
  · 动作 JSON 里写了**字面换行**（模型常见手滑）不再判"解析失败"，会自动转义成 \n

## 0.4.3
- 改进：技能目录与更新检查**优先走 GitHub API（实时）**，镜像只做兜底
  · 原因：jsDelivr 对 `@main` 这类分支地址会**缓存最多 12 小时** —— 刚加的技能、刚改的版本号要等半天才看得到
  · 来源顺序：GitHub API → jsDelivr → jsDelivr(Fastly) → GitHub 原始地址
- 改进：拉取失败时**自动重试一次**（CDN 抖动/被限流是常态，重试一下往往就好了）

## 0.4.2
- 重做：**自动化任务**（"点一下等两秒循环 3 次""PPT 逐页翻到底"这类重复动作，交给程序跑循环）
  · **按元素编号定位**：AI 把元素列表里的编号写进步骤（`{"op":"click","target":42}`），
    程序用它精确点到 AI 挑的那一个 —— 页头/页脚的同名"下一页"再也不会点错
  · **定位器**：开工时把编号翻译成"文字＋结构路径＋附近文字＋位置"，之后每轮自动找回；
    找不到就**停下来汇报**，绝不乱点
  · **就绪等待**：`waitFor` 等"目标按钮重新可点"或等某段文字出现，跨过"加载中"的窗口，不再死等毫秒
  · **变量与增减**：`vars` + `inc`/`dec` + `{变量}` 模板 —— 页码 1、2、3… 靠它（本轮动作没成时不改，避免脏数据）
  · **循环搬到侧栏**：能真正**取消**、能看到**逐轮进度**、每轮**验证页面是否推进**
  · `guard` 清弹窗、`stopIf` 被拦就停、`retry` 单步重试、`stallLimit` 停滞保护
- 改进：元素列表里**同名按钮会标出「同名 2/3 · 页面中部 · 附近「…」」**，AI 能挑对那一个
- 修复：更新弹窗点「知道了」/ 叉号关不掉（隐藏样式被同权重的 display 覆盖）

## 0.4.0
- 新增：**技能市场**。技能是一份写给 AI 看的操作说明书（Markdown），装到本地后在侧栏点一下就能让它照着干
  · 在线市场可浏览/搜索/安装/更新；本地技能可启停、在线编辑 Markdown 并保存、导出 .md、新建自己的技能
  · 侧栏输入框打 `/` 调用技能，**命中时整段变色**，一眼看出是否生效
- 新增：**版本更新提醒**。扩展更新后侧栏自动弹出更新日志；联网时还会提示仓库里有没有更新的版本
- 新增：**记忆自动压缩**（上下文用到设定比例时，自动把较早历史压成摘要）
- 新增：**AI 报错自动重试**（最多 5 次，等 5/6/7/8/9 秒）；仍失败自动切换下一个模型
- 新增：每个模型可单独设置**上下文上限**与**回复 Token 上限**
- 修复：更新弹窗点「知道了」/叉号关不掉
- 修复：离开标签页再回来时，会话看不到更新、横条不消失、按钮没变成"停止"
- 修复：后台任务续跑时抢走你正在浏览的页面；跨窗口串台；切到没有工作区的标签页却显示会话
- 修复：同一次唤醒被多份面板重复执行（请求成倍，触发 429 限流）
