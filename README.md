## 名字的由来

**青鸟**出自《山海经·西山经》——西王母"有三青鸟，为西王母取食"，是替神传信、先往探看的使者；
后世李商隐写下"蓬山此去无多路，**青鸟殷勤为探看**"，青鸟从此成了**替人跑腿、先去看个究竟、再回来报信**的意象。

这正好是这个扩展在做的事：**替你读页面、替你点按填写、替你在后台等条件、办完了回来告诉你**。
"青"也是它的主色；而多工作区，就像**青鸟分飞**——一只管一页，各办各的事，互不打扰。

## 它是什么

一个 Chrome / Edge 侧边栏 AI 助手。和普通"聊天框"不同的是，**它真的会动手**：

- 读当前页面（正文、表单、可点元素），按需截图理解；
- 点击 / 填写 / 选择 / 滚动 / 跳转，多策略定位，失败会换招重试；
- 需要你确认的动作会先问你，也可以开"自动执行"让它一路做完；
- 条件不满足时**挂后台任务**（等视频播完、等元素出现、等文字出现、定时），到点自动唤醒接着干——**你关掉侧栏、去干别的，它也在等**。

## 主要特性

### 多工作区：一个页面一份独立的对话
- 你在哪个页面提问，就为那个页面**单独开一份工作区**：自己的对话、自己的模型；
- 不同工作区**互不干扰、上下文互不可见**，可以同时各自跑任务；
- 工作区跟的是**标签页**（不是网址），同一个网址的两个标签页也是两份独立的活；
- 侧栏顶部有**工作区切换条**，点一下就能跳到那份工作区对应的页面；
- 不是当前工作区的页面，可以一键**并入**某个工作区（一起共用对话），也可以**移出**变回独立对话；
- 某个工作区的标签页全部关掉 → 该工作区连同它的会话一起消失。

### 后台任务
- `defer` 动作：等待**定时 / 元素出现 / 文字出现 / 视频播完**，满足后自动唤醒继续；
- 挂起时侧栏有横条显示在等什么；任务结束或取消，横条会自己收起；
- 唤醒**只会回到它自己那份工作区**，绝不会跑到你正在看的其它页面的对话里；
- 任务在后台续跑时，视图**不会被抢走**：你切到别的页面照常用，只有对应工作区的小圆点在提示"它在跑"。

### 可靠性与自愈
- **自动重试**：AI 报错自动重试，最多 5 次，等待 5 / 6 / 7 / 8 / 9 秒；
- **自动换模型**：同一模型重试 5 次仍失败，自动切换到同供应商的下一个模型继续（不改变你选择的默认模型）；
- **多 Key 轮换**：同一供应商可挂多个 Key，401/403/429 自动切换下一个；
- **记忆自动压缩**：上下文用到设定比例（默认 90%）时，自动把较早的历史压成摘要、保留最近几轮，继续干活；
- **跨面板自愈**：Chrome 侧栏是"每个标签页一份文档"，扩展会把会话、后台任务、运行状态都放在共享存储里同步——切走再切回来，看到的就是最新的。

### 模型与厂商
- 兼容 OpenAI 格式的接口，可添加多个供应商；
- 模型可选、每个工作区可以不同、也可以在任务中途改；
- 支持"深度思考"参数与视觉模型（附截图）。

## 安装

1. 下载或克隆本仓库，得到项目文件夹；
2. Chrome / Edge 打开 `chrome://extensions`（Edge 是 `edge://extensions`）；
3. 打开右上角「开发者模式」；
4. 点「加载已解压的扩展程序」，选择项目文件夹；
5. 点扩展图标即可打开侧边栏（或按 `Ctrl+Shift+Y` 打开侧边栏面板）。

首次使用：点侧栏右上角 ⚙ 进入设置 → 添加供应商（Base URL + API Key）→ 保存。
如果你用的是 Agnes，设置里有「探测域名」可以自动匹配接入地址。

## 使用

- 在任意网页打开侧栏，直接说话即可（"总结这页""帮我把这个表填了""点开第二节并播放"）；
- 需要连续操作的活儿，可以让它开自动执行，或一步步确认；
- 遇到要等的东西（视频、慢加载），它会挂后台任务，你可以先去忙别的；
- 想看某一页之前聊过什么：点顶部的历史会话，按工作区分组。

## 隐私

- **API Key 只存在你本机的 `chrome.storage.local` 里**，不上传任何服务器；
- 请求**由你的浏览器直连你填写的接口地址**，本扩展没有自建中转服务；
- 页面内容只在你让它"读页面/截图"时才被采集，并只发往你自己配置的模型接口。

## 目录结构

```
manifest.json          MV3 清单
background/            service worker：工作区注册表、后台任务表、面板清理
content/               注入脚本：页面读取与操作（多策略点击/填写/滚动等）
lib/                   存储、API 调用、模型协议、Markdown、工具函数
sidepanel/             侧边栏界面：index.html / sidepanel.js / workspace.js / css
options/               设置页
assets/                图标（16/32/48/128）与 Logo
brand/                 Logo 设计源图与生成脚本
test/                  端到端测试与本地页面夹具
docs/                  设计与调研笔记
```

## 开发与测试

端到端测试会**真实启动一个 Edge 实例**，加载扩展、打开夹具页面、用假的模型接口驱动完整流程：

```bash
node test/ws-check.mjs
```

它覆盖：懒创建工作区、多工作区并存与隔离、跨标签页/跨窗口不串台、后台任务挂起与唤醒、
唤醒不抢视图、自动重试与换模型、记忆压缩、会话按工作区隔离与连坐删除、品牌资源加载等。

> 依赖：本机安装了 Edge；脚本会自动拉起并连上它（CDP），跑完自动关闭。
> 测试用本地 HTTP 夹具服务（`test/fixtures/`）与假的模型流式响应，**不消耗任何 API 额度**。

## 已知限制

- 侧栏是"每个标签页一份文档实例"，扩展靠共享存储同步状态；极端情况下（例如同一工作区被两份面板同时操作）会自动转交，但并发体验仍在打磨；
- 自动换模型只作用**当次请求**，不会改动你在设置里选的模型；
- 旧的 `test/e2e.mjs` 大套件在一次本地事故中损坏，正在逐步恢复；当前以 `test/ws-check.mjs` 为准。
