# 青鸟技能市场

这里是「青鸟」浏览器助手的**在线技能目录**。扩展里的「技能市场」页面会自动读取本目录下的
[`index.json`](./index.json)，把技能列出来，一键安装到本地使用。

## 目录结构

```
market/
  index.json              技能目录（由脚本生成，别手改）
  build-index.mjs         生成 index.json 的脚本
  skills/
    <技能 id>/
      SKILL.md            技能本体（frontmatter + 说明正文）
```

## 什么是技能

一个技能就是**一份写给 AI 看的操作说明书**：什么时候用它、按什么步骤做、有哪些禁忌。
技能不写代码，它就是一段结构化的 Markdown —— 所以任何人都能写、都能改。

## 写一个新技能

1. 在 `market/skills/` 下新建一个文件夹，名字用技能 id（小写字母 + 连字符）；
2. 在里面放 `SKILL.md`，开头必须是 frontmatter：

```md
---
name: my-skill            # 技能 id，与文件夹同名
title: 我的技能            # 显示名（中文）
description: 一句话说清它替你做什么   # 会显示在列表里
version: 1.0.0
author: 你的名字
tags: [标签, 标签]
icon: "🧩"                # 可选，列表里的小图标
---

# 我的技能

## 什么时候用
...

## 步骤
1. ...

## 注意
...
```

3. 跑一下生成脚本，把你的技能写进目录：

```bash
node market/build-index.mjs
```

4. 提交 PR。合并后，所有人的「技能市场」里就会出现它。

## 写作建议

- **先说清"什么时候用"**：模型靠这句话判断该不该用这个技能。
- **步骤要可执行**：写成"先读取页面里的 X，再点 Y"，不要写成"了解用户需求"这种空话。
- **写明禁忌**：哪些动作必须先问用户（付款、提交、同意条款），哪些情况必须停下来求助
  （验证码、登录、付费墙）。
- **别写代码**：技能是给模型看的说明书，不是脚本。需要新能力就去给扩展提 issue。
- **等条件用等待**：需要"等某件事发生"时，让 AI 用后台任务（`defer`）等，而不要反复刷新页面。
